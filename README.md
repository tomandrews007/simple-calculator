# Simple Calculator

A lightweight calculator built with vanilla HTML, CSS, and JavaScript. No dependencies, no build step.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Clear (`C`), sign toggle (`±`), and percent (`%`)
- Decimal support with division-by-zero error handling
- Keyboard support: digits, `.`, `+ - * /`, `Enter`, `Backspace`, `%`

## Usage

Open `index.html` in any modern browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Files

- `index.html` — markup
- `style.css` — styling
- `script.js` — logic
